# 传递文本

文本传递适合发送临时命令、网址、地址或其他不便手动输入的内容。它使用与文件分享相同的本地服务和访问令牌。

<ZoomImage :src="textScreenshot" alt="LocalShare 文本传递界面，显示文本编辑区和二维码" />

## 从 Mac 发送到浏览器

1. 在主窗口中切换到“传递文本”。
2. 输入或粘贴文本。
3. 使用手机扫描二维码，或者打开显示的访问链接。
4. 在浏览器中查看并复制文本。

编辑内容后，浏览器重新加载即可看到新文本。文本不会写入 LocalShare Server。Client 的文本保留方式遵循「设置 → 主界面」中的保留选项。

## 从浏览器发送到 Mac

局域网访客也可以在文本页面中输入内容并发送回 Mac。收到的新内容会显示在 Client 中，适合把手机上的链接或短文本快速传回电脑。

互联网收到的文本显示访问者的来源 IP；局域网来源仍优先显示可识别的设备名。

## 通过互联网传递

发送文本后，在本页点击「互联网分享 → 连接」，把公网链接发给访问者。纯文本、文件附带文本均可访问；更新文本后重新加载即可，链接继续有效。

若要让浏览器发回文本，单独打开「允许通过互联网收文本」。它默认关闭，与「允许局域网收文本」互不影响。单条上限 64 KiB，关闭开关后拒绝远程提交；文件上传仍只供局域网使用。

公网连接使用 HTTPS/WSS，中继可读取文本。Mac 需在线；断开撤销公网链接，停止文本传递会清除当前发布并关闭接收。

## 什么时候使用文件分享

文本传递面向短文本，不替代文件上传。需要发送文档、图片或其他二进制内容时，请使用[文件分享](./file-sharing)；需要让访客把文件传回 Mac，可以在局域网文件夹分享中启用访客上传。
