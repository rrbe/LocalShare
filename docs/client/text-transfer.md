# 传递文本

文本传递适合发送临时命令、网址、地址或其他不便手动输入的内容。它使用与文件分享相同的本地服务和访问令牌。

<ZoomImage src="../images/screenshot-share-text.png" alt="LocalShare 文本传递界面，显示文本编辑区和二维码" />

## 从 Mac 发送到浏览器

1. 在主窗口中切换到“传递文本”。
2. 输入或粘贴文本。
3. 使用手机扫描二维码，或者打开显示的访问链接。
4. 在浏览器中查看并复制文本。

编辑内容后，浏览器重新加载即可看到新文本。文本存放在当前 Client 进程中，不会写入 LocalShare Server。

## 从浏览器发送到 Mac

局域网访客也可以在文本页面中输入内容并发送回 Mac。收到的新内容会显示在 Client 中，适合把手机上的链接或短文本快速传回电脑。

::: info 远程模式的限制
远程访问只提供只读文件浏览，不提供 Text Transfer，也不会把浏览器提交的文字转发到 Client。
:::

## 什么时候使用文件分享

文本传递面向短文本，不替代文件上传。需要发送文档、图片或其他二进制内容时，请使用[文件分享](./file-sharing)；需要让访客把文件传回 Mac，可以在局域网文件夹分享中启用访客上传。
