# 传递文件

LocalShare 会把选中的内容映射到临时浏览地址。浏览器可以逐层浏览目录、预览支持的格式或下载原文件，而 Mac 上的源文件不会被复制到其他位置。

## 支持的分享方式

| 选择内容 | 浏览器中的表现 |
| --- | --- |
| 单个文件 | 直接预览或下载该文件，无法访问同目录中的其他内容 |
| 单个文件夹 | 浏览文件夹目录，并访问其内部文件 |
| 多个项目 | 在虚拟根目录中展示所有选中的文件和文件夹 |

常见的 HTML、PDF、视频和图片可以直接由浏览器打开。Markdown、JSON 和 CSV 会显示专用预览页面，也可以使用原始内容地址下载。

## 更换分享内容

重新选择文件或文件夹时，LocalShare 会立即轮换访问令牌。旧链接、旧二维码和旧浏览器 Cookie 随即失效，不会继续指向新内容。

停止分享也会使当前链接失效。关闭窗口不会退出应用；只要分享仍在运行，菜单栏中的 LocalShare 仍可继续提供服务。

## 访客上传

分享单个文件夹时，可以按需允许局域网访客上传文件。上传内容只会写入当前分享目录，并经过文件名清理、路径检查、大小限制和隔离标记处理。

远程 Server 模式始终只读，不支持访客上传。

## 访问范围

LocalShare 会解析标准化路径和符号链接，浏览器只能访问明确选择的文件或目录。即使请求包含 `..`、百分号编码路径或指向外部的符号链接，也不能越过分享根目录。
